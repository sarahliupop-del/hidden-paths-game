# HIDDEN PATHS — Collect the Character. Enter the Story.

A student collectible concept for NINJAGO fans aged 13–17. Six characters, built-in NFC, private interactive stories.

Static site (no build step). Deployed via GitHub Pages.

- `index.html` — main page (optimized: images extracted to `assets/`, scroll-reveal animations, hero entrance motion, OG meta, reduced-motion support)
- `assets/promo.mp4` — dynamic teaser video
